# Çözümler

⚠️ **UYARI: Bu klasöre sadece egzersizleri tamamladıktan sonra bak!**

Bu klasörde egzersizlerin çözümleri var:

1. **hello_world_handler.py** - Hello World Lambda çözümü
2. **hello_world_template.yaml** - Hello World SAM template çözümü
3. **s3_reader_handler.py** - S3 Reader Lambda çözümü
4. **s3_reader_template.yaml** - S3 Reader SAM template çözümü

## Nasıl Kullanmalısın?

1. Önce egzersizi kendin yap
2. Çalışmazsa hata mesajlarını oku
3. Hala takılırsan buraya bak
4. Kendi kodunla karşılaştır

## Öğrenme Süreci

Doğrudan çözüme bakmak yerine:
- Hata mesajlarını oku
- AWS dokümantasyonuna bak
- Google'la
- Sadece çok takılırsan çözüme bak

Böylece gerçekten öğrenirsin! 🎓
